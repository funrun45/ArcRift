How to use

Playing

  • Press Start VR session and approve the administrator prompt. A PowerShell window opens; leave it open, it restores everything at the end.
  • When the status says Running, start your SteamVR game (for example from Steam in VR mode). Tested with VRChat.
  • Optional: after Running, use Proximity bypass… and set Bypass Proximity Sensor Check to On. Close the Debug Tool before stopping.
  • When finished, quit the game, then press Stop & restore and wait until the status says the session was restored.

Good to know

  • Taking the headset off pauses the freeze check; putting it back on resumes.
  • If the headset is put down and sits still for a while, Meta's runtime can freeze when it is picked up. The session then stops and restores itself; just start a new one.
  • Sessions stop automatically on real trouble (frame-rate collapse, GPU errors, Meta/SteamVR exiting) and restore your display and Meta settings.
  • If the PowerShell window was closed or crashed before cleanup finished, a red banner appears: press Recover with the headset plugged in. Restoring… means automatic recovery is already running: wait for it.
  • If Recover finished but Needs recovery stays (usually your monitor setup changed during the session), press Clear…. It changes nothing; it re-checks the Meta settings, headset display mode and plugins, then clears the warning.
  • Each session gets a folder (d3d11-…) with logs and, if PresentMon.exe is present, frame timings (presentmon.csv).

Never

  • Never close the administrator PowerShell window during a session.
  • Never run two copies of this folder at the same time.
